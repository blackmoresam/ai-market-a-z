# AI Market A–Z

**Discover AI tools beyond the big chatbots.**

A free, curated directory of AI tools covering everything from coding and automation to creative design, research, business operations and specialist applications.

## What's included?

- 250+ AI tools across a wide range of categories
- Clear descriptions of what each tool does
- Who each tool is designed for
- Links to official product websites
- A filterable Excel spreadsheet for easy exploration

## Why I created this

I started exploring AI beyond ChatGPT, Claude and Gemini and quickly realised how much of the market I knew very little about.

I created this directory to broaden my own understanding of what's available and what different tools can actually help people accomplish.

I've made it freely available in case others find it useful too.

## Download

Download the latest Excel spreadsheet from the **Releases** section of this repository.

No registration, email address or payment required.

## A note on accuracy

The AI market changes quickly. This directory is intended as a starting point for discovery, not a definitive assessment or endorsement of every tool listed.

Product information may change, so check official websites before making decisions.

## Updates

I'll update the directory as I discover new tools and meaningful changes to existing ones.
